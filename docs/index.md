# TopoMT

TopoMT studies molecular surface topography through explicit geometric models,
native DFND analysis and integrations with original third-party methods.

Start with [DFND: Theory and Method](content/dfnd/index.md) to understand the
model, or explore [Topography BenchLab](content/benchlab/index.md) for controlled
systems, independent references, observed results and current limitations.

## Development status

The project is under active development. The current source studies and public
API examples have bounded qualification; they do not establish biological
accuracy, a complete feature catalog or installed-package support on every
platform. See [installation](content/about/installation.md) for the actual
source-development route and its dependency requirements.
