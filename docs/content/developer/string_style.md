# String and Quotation Style

Use these conventions for strings and docstrings across the repository.

## Strings

- Use single quotes by default.
- Use double quotes when the string itself contains an apostrophe.
- Preserve required double quotes for formats such as JSON.

## Docstrings

- Use triple double quotes for docstrings.
- Keep the first line as a concise summary.
- Follow with a blank line before any extended description.

## Formatting tools

Contributors are expected to rely on the repository formatting and linting
workflow, using `ruff format` and `ruff check` as the canonical tools.
