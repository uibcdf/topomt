# Molecular systems

This collection will contain studies of real molecular systems. It is planned;
no molecular BenchLab case is published here yet. Current DFND work proceeds
through the [synthetic collection](../synthetic/index.md) before starting new
protein-characterization work.

Each molecular case will use the same study-unit structure as the synthetic
cases: one stable descriptive directory, a notebook, versioned inputs and
traceable observations. Additional molecular context will include:

- Structure source and revision, model/frame, assembly, chains and participants.
- Preparation, alternate locations, hydrogens, modifications, radii and probes.
- Independent annotations or experimental evidence appropriate to the question,
  with their uncertainty and limits.
- Reproducible original-method comparisons with compatible scientific meaning.
- For an ensemble or trajectory, frame selection and sampling context, keeping
  dynamic observations distinct from single-frame geometry.

Existing molecular tests and historical provider studies elsewhere in the
repository keep their own scope. They do not become qualified BenchLab cases
merely because this collection has been opened.
