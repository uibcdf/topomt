## Admission and catalogue intake

Support routes a researcher can use without paying: locally installable open
source or a no-cost service. Review the exact edition, version, licence and
permitted use; a public repository or free website alone proves neither open
source nor reliable automated access. Paid products are outside the present scope.
Server availability, terms, permitted automation and coordinate disclosure
remain separate requirements. Never submit a structure just to test availability.

Add leads to [the catalogue](external_tools_catalog.md) and reuse the canonical
[resource conversation](discussion_resources.md). Record official sources,
scientific object, input constraints, access/licence, installation requirements,
reviewed revision/date, proposed routes, owning issue and next evidence gate.
Unknown information stays unknown. Separate documentary review, implemented
adapter, executed original engine, installed-package receiving and full scientific
qualification. A parser fixture is evidence for parsing, not detection.

## Implementation sequence and gates

1. Consolidate existing original-provider dispatch, original evidence and saved
   recovery contracts. Preserve known issues rather than hiding external failure.
2. Add neutral geometry access and distinct cavity/channel/site record kinds,
   retaining existing pocket APIs and avoiding canonical DFND admission by labels.
3. Implement each original runner and reader against its frozen documented
   protocol. Reuse MolSysMT export/source/selection/frame/chemistry tools;
   keep atom memberships and unavailable mappings honest.
4. Capture original outputs, configuration, submitted coordinates, executable or
   module identity, settings, units and source context before temporary directories
   disappear. Saved recovery validates source and evidence without an engine.
5. Exercise valid, empty, malformed, incompatible-source, absent dependency,
   selected-command failure and argument/unit/resource boundaries. Then compare
   a small original execution directly with the adapter's parsed result.
6. Record actual host, dependencies, checks, durations, input/output hashes and
   limitations. Batch installed qualification at a coherent milestone, following
   [the existing handoff plan](provider_handoff_plan.md); do not substitute these
   source checks for #16/#58/#81 or exhaustive fidelity #19.

pyKVFinder and GHECOM grids do not certify a continuous closed region. CAVER
centerlines are paths, not a tunnel volume. P2Rank's molecular learned-site
predictions do not provide ground truth for synthetic hard-sphere geometry.
New original-provider molecular smoke checks do not start native DFND protein
characterization or the molecular BenchLab collection.
