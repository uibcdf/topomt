# Original external HOLE

Owner: [#192](https://github.com/uibcdf/topomt/issues/192); broader HOLE/CHAP
assessment stays [#161](https://github.com/uibcdf/topomt/issues/161).
Read the [user contract](../../docs/content/user/hole.md) and
[exact source/execution checkpoint](../specialist_provider_checkpoint.md).

The adapter invokes the original spherical executable with fixed relative
input filenames, explicit origin/direction, radius resource and random seed.
It preserves the input cards, resource bytes, executable identity and complete
stdout/sphere data. Normal completion, atom inventory, original profile and
sphere consistency are required; exit zero alone is insufficient.

The parser keeps sampled and midpoint rows distinct. `Rmin` is the original
sampled-node minimum. Signed distances/negative clearances remain signed; a
negative profile is not coerced into positive sphere radii. Original QSS rows
with index -888 are artificial visualization extensions. The repeated origin
must agree rather than creating another sample. Centerline segment distances
are checked against the original table at its stated coordinate precision.
There is no lining-atom map, swept-volume inference or native channel admission.

The source-bound reader verifies control/resource fingerprints, the input-card
echo, source frame/selection/chemistry and original query/version. It needs no
Fortran executable. Original attribution records the completed software/method;
the recognized original AMBER table conditionally adds its data reference.
Arbitrary custom tables retain bytes without invented publication credit.

The frozen argon and carbon controls share coordinates but use distinct
radius/input models; neither is a new DFND comparison. Future general-field,
profile, installed/platform or transport claims need their own scoped evidence.
