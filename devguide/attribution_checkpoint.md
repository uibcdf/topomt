## Delivered boundary

The current original/native/corrected provider routes, DFND queries and directly
reached scientific helpers use deferred optional Ackredit completion boundaries.
Applications retain session ownership. Results retain detached declarations,
recording status, producer versions and portable captured bibliography.
Native methods distinguish their criterion/reference implementation from the
software executed. Fpocket druggability has its own conditional citation, as
requested in the inspected upstream documentation.

`topomt.get_attribution(result)` reads the host metadata without Ackredit.
`topomt.cite(result)` renders through its public reader, without new registration
or calculation credit. A contradictory partial bibliography is refused rather
than replacing an originally observed record. Version-2 provider bundles protect
attribution separately from the unchanged scientific run ID and original bytes;
version-1 bundles remain readable and keep unrecorded historical attribution.

The obsolete Flowcite shim is retired. Root AGENTS links the maintenance rules.
Ackredit is optional, classified through DepDigest and included in the development
tooling group. It is not a new required runtime dependency or qualified PyPI extra.

## Execution and preservation

All calculations were sequential, restricted to one CPU with numerical thread
counts set to one. Memory address space was capped at 6 GiB, and CPU-time limits
were 30–120 seconds per process. The host had about 55 GiB available from 61 GiB
physical RAM and no memory PSI pressure at the checks. No Slurm allocation was
used; scheduler inspection was unavailable in this process. Free resources were
not treated as a reservation.

No existing BenchLab input/output, molecular reference, synthetic asset or
frozen scientific evidence was rewritten. No original coordinates were sent to
a service. No dependency was installed or shared environment changed. The
pre-existing local version-file edit was preserved and excluded from delivery.

The inventory repair registers the pre-existing optional original-provider build
profile without changing its bytes, adds 42 previously omitted source/assets and
the three new attribution modules to the package-resource list, and corrects
stale route-count/source-admission controls. Its separate report retains #169's
scope; an administrative synthetic archive is not a built TopoMT deliverable.

## Scope retained for later qualification

This is source integration. It neither qualifies every original tool/version nor
establishes scientific parity, a public package, a supported installed matrix or
the complete repository suite. The wider source/installed/public obligations
remain under [#16](https://github.com/uibcdf/topomt/issues/16); broader ecosystem
adoption remains under [#56](https://github.com/uibcdf/topomt/issues/56).
Receiving must ensure Ackredit is actually present when running these guards;
an optional-provider skip does not establish real-provider coverage. Existing
scientific issues, including the CAVER/MOLE investigations, retain their owners.

Discussion closeout preserves the resource history and updates the current
attribution summaries in the methods index and affected provider/DFND threads.
The live issue/Discussion readback is recorded in #157 at publication. Incremental
delivery uses the maintainer-authorized `[skip ci]` route; remote CI and full
Python/installed qualification are deferred to #16, not represented as passing.
