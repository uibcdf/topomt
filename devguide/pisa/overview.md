# Original external PISA

Owner: [#194](https://github.com/uibcdf/topomt/issues/194); broader PISA/PePrMint
assessment stays [#165](https://github.com/uibcdf/topomt/issues/165).
Read the [user contract](../../docs/content/user/pisa.md),
[licence/availability review](license_review.md) and
[exact source/execution checkpoint](../specialist_provider_checkpoint.md).

The adapter calls an externally acquired PISA 2.1.2 executable and its original
runtime resources. It analyzes the supplied assembly using `--as-is`, creates
a private task-owned session root, and retains original analysis, XML, monomer
inventory and version output. The version command's successful code is 2;
analysis/extraction require zero and independent result postconditions. Binary
session files are task-local; the reusable capture retains human-readable
results, configuration and resource fingerprints, not redistributed datasets.

The parser requires explicit successful XML, matching row/contact counts, two
distinct participants and a supplied-assembly summary. The original “Assemblies
not calculated” description is expected for this route and does not erase its
ASU summary. Monomer Nat counts must retain every submitted atom. Contacts map
through exact submitted atom/residue/chain identities to source indices; reported
contact atoms and buried-area atoms are different sets. Label/auth identifiers,
insertion codes, contact groups, original area and model energy units survive.

DTD/entity declarations, ambiguous maps, missing/failed XML and query/policy
conflicts are refused. Evaluated zero interfaces remain valid. No probable
biological assembly, DFND interface classification, crystal expansion or binding
energy truth is inferred. Saved reading needs neither executable nor setup data
and earns no new scientific credit.

The research-use/free-academic acquisition evidence is distinct from a complete
standalone modification/redistribution grant. Preserve the review's unresolved
scope under #165; the adapter does not bundle PISA or its resources. No external
licence issue is authorized by this integration, and the retained draft remains
unpublished. Original source headers and the 2007/2026 descriptions supply the
completed-route bibliography; wrapper/data licences are not engine licences.
